# Fonts

Download variable fonts from Fontshare and place them here:

1. **Zodiak** (Display): https://www.fontshare.com/fonts/zodiak
   - Download the Variable font
   - Rename to `Zodiak-Variable.woff2`

2. **Satoshi** (Body): https://www.fontshare.com/fonts/satoshi
   - Download the Variable font
   - Rename to `Satoshi-Variable.woff2`

Expected files:
- `Zodiak-Variable.woff2`
- `Satoshi-Variable.woff2`
